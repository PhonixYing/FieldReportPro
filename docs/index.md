## What It Does

Field Report Pro is a paid iOS app for contractors, home inspectors, landlords, property managers, and field service teams.

Use it to:

- Create a report with client, property, date, and report type
- Add issue entries with title, severity, location, notes, and photos
- Import images from the photo library or capture them with the camera
- Export a professional PDF from the field

## Why Teams Use It

- No account required
- No subscription
- Works offline
- Simple PDF report workflow
- Designed for fast on-site documentation
